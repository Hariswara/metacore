# Reports — SLIIT FoC Data Science deliverables

Placeholder folders so the mandatory checklist items are tracked from day one alongside the code
rather than assembled at the end.

| Folder | Deliverable | Owner |
|---|---|---|
| `literature-review/` | Literature review | All (per module) |
| `data-analysis-report/` | Data Analysis Report | All (per module) |
| `mlops-report/` | MLOps Report | All (per learned module) |
| `ethical-analysis-report/` | Ethical Analysis Report | Team |
| `proposal/` | Project proposal and charter | Team |

The project requires no formal ethical clearance — no human subjects, no personal data, no clinical
or biological sampling. AIS and weather data are public, simulated or grid-aggregated and
anonymised, and node coordinates are published only as arbitrary spatial offsets. The ethical
analysis report records that reasoning rather than assuming it.
